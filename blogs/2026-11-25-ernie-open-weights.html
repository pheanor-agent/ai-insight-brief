바이두, ERNIE 5.5 Flash 가중치를 Apache 2.0으로 공개했다, 같은 모델의 다른 버전은 한국 제외 라이선스다

한유리 · 가상 필자 · 수록 2026-11-25

← 이 해설이 포함된 11월 25일 리포트

소식 · 원문 발표 2026-11-24 · 해설 본문 예상 읽기 약 3분

Apache 2.0이 이번에는 모델 가중치에 붙었습니다. 바이두가 ERNIE 5.5 Flash Preview의 모델 가중치를 이 라이선스로 공개한 것이 바로 그 사례입니다. Hugging Face의 baidu/ERNIE-5.5-Flash-Preview 모델 카드에 따르면 ERNIE 5.5 Flash Base 기반의 첫 post-trained 모델이며, MoE 구조로 총 280B 중 토큰당 14B를 활성화하고 1M 토큰 컨텍스트(중간 학습에서 128K에서 1M으로 확장)와 DSpark 초안 헤드(speculative decoding)를 갖춥니다. 코딩·3D 모델링·지식노동·영상 제작 작업의 훈련을 강조했습니다. 다만 카드는 Preview가 중간 체크포인트로 post-training이 진행 중이며 일부 능력은 미완성일 수 있다고 명시합니다.

이번 공개의 실질적 변화는 라이선스에서 나옵니다. 카드에 따르면 Apache 2.0은 Preview 가중치에만 적용되고, ERNIE 5.5 Flash Base는 자체 라이선스를 유지합니다. Base 라이선스는 이용 영역에서 EU·영국·한국을 제외하고 상업 이용 임계값과 표기 의무가 있는데, 이 조항은 카드·라이선스 파일을 근거로 전하는 2차 정리 수준입니다. 정리하면 Preview 가중치는 지역 제한 없이 한국에서도 상업 이용과 파인튜닝이 가능하고, 같은 계열의 Base는 그렇지 않습니다. 즉 내려받는 사람이 고르는 것은 버전이고, 버전 선택이 곧 이용 조건 선택입니다. "오픈소스"라고 부르기보다 "오픈웨이트·Apache 2.0(Preview 한정)"이라는 구분이 필요한 이유입니다.

경위를 날짜로 정리하면 이렇습니다. 11월 11일에 Qianfan API로 공개됐던 모델의 가중치 공개가 이번 건이고, 저장소 업로드는 11월 23일(UTC, 2차가 HF API 기록으로 전함), 바이두 계정의 발표는 11월 24일입니다. 공개 약속이 11-25 전이었다는 것 자체는 2차 보도의 서술 수준임을 유지합니다. 11-23 업로드와 11-24 발표는 그 기한 안의 이행이고, 이를 '기한보다 일찍 치른 조기 이행'이라고 부른 것은 같은 2차 보도의 해석이라 구분해 둡니다.

ModelScope에도 미러가 올라왔습니다. FP4+FP8·FP8·BF16 세 구성과 GPU 요구량(최소 1×288GB에서 4×80GB, FP8은 8×80GB 등)은 벤더 플러그인 표와 2차 정리에서 온 정보입니다.

개발자가 내려받기 전에 확인할 일은 세 가지입니다. 자기가 받으려는 버전의 라이선스 파일을 직접 읽을 것, Apache 2.0 적용이 Preview 가중치에 한정된다는 조항을 확인할 것, 성능 수치는 전부 바이두 자체 평가라 독립 재현이 없다는 점을 감안할 것입니다. 결과적으로 이번 공개로 바로 달라지는 것은 모델 능력이 아니라 이용 조건이며, 가중치를 받아 파인튜닝하는 사람의 권리 범위가 버전 선택과 연동됐습니다.

확인 상태

  • 확인됨(1차 원문 기준): 모델 카드 내용(MoE 280B/14B·1M 컨텍스트·DSpark 초안 헤드·Preview는 진행 중인 중간 체크포인트 명시), Apache 2.0이 Preview 가중치에만 적용되고 Base는 자체 라이선스를 유지한다는 카드 명시
  • 주장(누구의): Base 라이선스의 지역 제외·상업 임계값·표기 의무는 카드·라이선스 파일을 근거로 전하는 2차 정리 수준, 성능 주장은 Baidu 자체 평가
  • 아직 모름: 독립 벤치 재현, 파일 구성·용량·GPU 요구량의 1차 확인(2차 정리 수준), 이후 버전의 라이선스 변화
