SenseNova U1.6, 자기 그림의 오타를 스스로 고친다

윤서진 · 가상 필자 · 수록 2026-11-26

← 이 해설이 포함된 11월 26일 리포트

소식 · 원문 발표 2026-11-24 · 해설 본문 예상 읽기 약 5분

SenseTime은 11월 24일 이해·생성 통합 U시리즈의 8B 모델 SenseNova U1.6을 공개하고 모델 가중치도 함께 내놓았습니다. 시리즈 최초로 네이티브 이미지 자기수정을 제공합니다. 잘 나온 포스터를 확대해 보니 영어 단어 철자가 틀렸다면, 지금까지는 같은 프롬프트를 다시 굴리거나 편집 도구로 고쳐야 했습니다. 이 모델은 초안을 스스로 검사해 고친 판을 한 번의 생성 안에 내놓습니다.

순서는 이렇습니다. 같은 모델이 초안을 만들고, 원래 프롬프트와 대조해 검사하고, 글자 흐림·오타·영어 철자·번호 오류가 보이면 구체 수정 지침을 세운 뒤 수정판을 생성합니다. 발표문은 이전에는 사용자가 검사하고 피드백을 주고 다시 고쳐 달라던 일을 모델이 맡는다고 적습니다. 회사가 공개한 수정 전·후 비교는 영어 문구가 크게 들어간 비즈니스 홍보 포스터입니다. 자기수정 훈련은 정보그래픽이 대상이고, 일부 비정보그래픽 장면으로의 일반화를 관찰했다는 것이 회사 서술입니다.

수치는 전부 회사 자체 평가입니다. 내부 사용자 평가에서 U1.6 Lite의 미학 점수가 U1.5 Lite보다 약 10% 높습니다. UltraTextBench 밀집 정보그래픽 테스트에서 U1.6 Lite는 단일 생성 86.04에서 자기수정을 켜면 92.28로 오르고, 상대 차이는 약 7%입니다. 독립 재현은 아직 없습니다.

가중치는 Hugging Face 모델 카드 sensenova/SenseNova-U1.6-8B-MoT에서 신청 없이 내려받을 수 있습니다. 라이선스는 Apache 2.0이고 U1.5 공개와의 일관성을 명시했습니다. 저장소 파일은 BF16 샤드 safetensors이고 설정·토크나이저 파일이 함께 놓여 있습니다. 모델 구현은 별도 GitHub 저장소에 있고, 카드의 추론 예시는 1024×1024 이미지를 50스텝으로 뽑는 명령 하나입니다. 발표문의 오픈소스화 표현과 달리 실제 공개 범위가 모델 가중치와 설정 파일인 만큼, 이 글에서는 오픈웨이트라는 구분을 씁니다.

여기서 하나 걸리는 대목이 있습니다. 카드에는 모델 크기가 18B params(BF16)로 적혀 있는데 이름은 8B이고, 실제 파라미터 수는 약 175억입니다. 카드에 이 차이에 대한 설명은 없습니다. 내려받기 전 용량을 가늠할 때는 이 값을 기준으로 삼는 편이 낫습니다. 파생 저장소는 형태별로 나뉩니다. 본체 BF16 통합본이 35.07GB이고 양자화는 FP8·INT8 18.87GB, GGUF는 Q4_0 12.28GB부터 Q8_0 20.70GB까지 있습니다. 4·8-step LoRA도 Python과 ComfyUI용으로 나와 있습니다. 실행에는 OpenSenseNova/SenseNova-U1 런타임과 CUDA가 필요하고, 카드는 U1.5 인터리브드 생성 가정을 검증 없이 그대로 쓰지 말라고 적습니다. ComfyUI 정식 지원은 11월 24일 릴리스 로그에 나옵니다.

사라지는 수고가 이 모델의 직접 효과입니다. 모델이 내준 그림을 확대해 글자를 하나씩 읽고, 틀린 곳을 짚어 고쳐 달라고 다시 명령을 내리던 일 가운데 검사와 수정 지침 작성, 재생성이 모델 쪽으로 넘어갑니다. 신청 절차 없이 내려받아 로컬에서 돌릴 수 있게 된 것도 사용 조건을 바꿉니다. 남는 수고도 분명합니다. 검사 항목이 글자 흐림·오타·영어 철자·번호 오류로 정해져 있어, 글자 밖의 그림 상태는 이 절차가 확인해 주지 않습니다. 카드 한계 절은 복잡 레이아웃·밀집 텍스트·소형 인물 디테일·장편 다중참조 편집이 추가 검증 대상이라고 적습니다. 비정보그래픽 장면에서 자기수정이 어디까지 통하는지는 각자의 장면에서 직접 확인해야 하고, 성능 수치를 인용할 때는 회사 자체 평가라는 조건을 함께 쓰는 일도 여전히 남습니다.

확인 상태

  • 확인됨: U1.6 공개와 가중치 공개, 자기수정 절차(초안 생성→프롬프트 대조 검사→수정 지침→수정판 생성)와 훈련 대상이 정보그래픽이라는 서술, 발표문이 적은 사용자 검사·피드백·재편집 일의 모델 이관, 수정 전·후 비교 예시(영어 문구가 큰 비즈니스 홍보 포스터), Apache 2.0·신청 없는 다운로드·저장소 파일 구성(BF16 샤드 safetensors·설정·토크나이저)·구현의 별도 GitHub 저장소 위치·카드 추론 예시(1024×1024·50스텝)·U1.5 인터리브드 생성 가정 경고·파생 저장소 목록과 크기·실행 조건·ComfyUI 정식 지원, 카드 표기 18B params(BF16)와 이름 8B·실제 파라미터 수 약 175억의 불일치(모델 카드 한계 항목 기록, 원문 대조)
  • 주장(SenseTime·회사 자체 평가): 내부 사용자 평가의 미학 점수 약 10% 향상, UltraTextBench 86.04→92.28(상대 약 7%), 일부 비정보그래픽 장면으로의 일반화 관찰
  • 아직 모름: 독립 재현 수치, 8B와 18B·약 175억 표기 차이에 대한 공식 설명, 복잡 레이아웃·밀집 텍스트 등에서의 실측(카드가 추가 검증 필요로 표기), 글자 밖 그림 상태에 대한 자기수정 효과

자기수정을 새 기능 소개가 아니라 같은 모델의 초안과 검사·수정 두 단계로 풀어 설명한 점을 높이 샀습니다. 가중치를 받아 쓰는 독자에게는 성능 수치보다 라이선스와 표기 차이의 조건이 실제로 중요한데, 그 순서를 지켰습니다. 오픈웨이트로 넘어온 자기수정이 별도 검사 도구 파이프라인을 얼마나 대체할지 지켜볼 질문으로 남깁니다.
