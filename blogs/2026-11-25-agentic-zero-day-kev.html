AWS가 에이전트가 스스로 찾은 제로데이를 보고했다, CISA는 사흘 뒤 기한을 붙였다

윤서진 · 가상 필자 · 수록 2026-11-25

← 이 해설이 포함된 11월 25일 리포트

소식 · 원문 발표 2026-11-20 · 해설 본문 예상 읽기 약 4분

약 11분이면 충분했습니다. Amazon Threat Intelligence가 11월 20일 보고한 바로는, 공격자가 풀어놓은 자율 에이전트는 오픈소스 의료영상 라벨링 도구 MONAI Label의 API 엔드포인트를 매핑한 뒤 업로드 필드의 경로 탐색 취약점을 찾았고, 약 11분 만에 서버에 임의 파일을 쓰는 데 성공했습니다.

보고(CJ Moses, 2026-11-20)에 따르면 공격자는 2026-09-08부터 약 48시간 동안 동아시아(중국 본토 외)의 대학 IP를 표적했습니다. 에이전트에게 내린 목표는 "obtain shell access" 한 줄이었습니다. 경로는 9월 10일부터 인증 없이 인터넷에 공개돼 있던 Cairn(오픈소스 AI 자율 침투 프레임워크) 서버였고, Amazon은 프롬프트와 운영 기록을 관측했습니다. 프롬프트가 중국 간체였고, 스크립트 타임스탬프가 중국 표준시였으며, 표적의 성격을 근거로 Amazon은 중국 연계 공격자를 중간 신뢰도로 추정합니다. 국가의 지시라는 단정까지는 아닙니다.

에이전트의 성공은 한 번으로 끝나지 않았지만 만능도 아니었습니다. 한 대학 Redis 서버에서는 약 16시간 동안 148개 연속 행동이 실패했고, 별도 GPU 서버에서는 공개 정보로 사용자명 약 80개를 구성해 SSH에 3만 조합 이상을 시도하다 실패했습니다. 성공한 MONAI Label 표적에서는 이후 세션에서 sitecustomize.py에 파이썬 역시피어를 심어 root 권한 셸을 확보했습니다. 당시 이 취약점은 자문·이슈·권고가 전혀 없었기에 Amazon은 제로데이로 판정했습니다(고신뢰도). 사람도 개입했습니다. 공격자는 에이전트에 2차 대학망으로 드나드는 터널을 제공하고, 같은 취약점으로 뚫은 서버를 경유해 내부 표적을 지시했습니다.

취약점의 실체는 프로젝트 쪽 권고(GHSA-qc22-rmgc-vg94, 11월 18일)가 확인합니다. PUT /datastore/image의 image 파라미터가 경로 검증 없이 파일 ID로 쓰이면서 임의 파일 쓰기·원격 코드 실행(CWE-22)이 가능했고, 영향 버전은 0.8.5 이하, 패치는 0.8.6(#1915)입니다. 결정적인 조건은 기본 설정이었습니다. 인증이 비활성화된 기본값이라 접근 가능한 임의 클라이언트가 악용할 수 있었고 ANNOTATOR 역할로도 충분했습니다.

이 보고의 요점은 수고의 재분배입니다. 취약점을 찾는 쪽의 수고는 줄었습니다. 사람 대신 에이전트가 11분에 찾아냈으니, 공격자 입장에서 없어진 수고입니다. 반대로 방어자의 수고는 늘었습니다. Amazon은 대응 창이 분 단위로 압축됐다고 결론짓습니다. 뒤따르는 절차는 여전히 사람의 몫이었습니다. 유지보수자의 권고 공개(11-18), MONAI Label 0.8.6 보안 릴리스(2차 확인 경유), 그리고 CISA가 CVE-2026-133968을 11-23 Known Exploited Vulnerabilities에 올려 연방기관 패치 기한을 11-26으로 정한 일입니다. 다만 이 CISA 등재 세부는 2차 보도(11-24) 경유라는 점은 표기해 둡니다.

도움을 받는 사람은 이 단계에서 명확히 갈립니다. 표적을 잘 고른 공격자가 이득을 봤고, 방어자는 KEV 기한이라는 제도가 패치 일정을 강제해 준 것에 의지합니다. 조건도 붙입니다. 성공은 인증 비활성화라는 취약한 기본 설정에 의존했고, 에이전트 작업 다수는 실패했으며, 공격자 모집단의 전체 규모와 다른 표적은 아직 미확인입니다.

확인 상태

  • 확인됨: 캠페인 기간·표적·실패·성공 경로의 수치, MONAI Label 취약점 내용(CWE-22·영향 0.8.5 이하·패치 0.8.6·기본 인증 비활성), 0.8.6 보안 릴리스(2차 확인)
  • 주장(누구의): 중국 연계 귀속은 Amazon의 중간 신뢰도 추정. 제로데이 판정도 Amazon의 고신뢰도 판단
  • 아직 모름: 국가 지시 여부, 공격자 모집단 규모와 다른 표적, CISA 등재 세부의 1차 원문 확인
