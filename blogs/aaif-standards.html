Google Open Source Blog의 인터뷰는 MCP와 Agent Skills의 역할을 나눠 설명합니다. MCP는 에이전트가 실시간 도구에 연결하도록 하고, Agent Skills는 절차 지식과 스크립트를 필요할 때 불러오는 형식입니다. 인터뷰에서 Google은 Anthropic이 Agent Skills 명세를 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기증했고, Google·Anthropic·OpenAI 엔지니어들이 벤더 중립 거버넌스 아래 이를 공동 유지보수한다고 소개합니다. 이는 인터뷰가 전한 관리 구상이지, 실제 상호운용성이나 기증 뒤 유지보수 성과를 확인한 결과는 아닙니다. 표준의 이식성은 구현과 채택으로 확인할 과제입니다.
