Anthropic, Messages API의 Rust 전환을 무중단으로 완료 — CPU 70% 절감

소식 · 원문 2026년 11월 · 해설 본문 예상 읽기 약 4분

Anthropic이 25일 API 고객과 Claude Code·Cowork가 쓰는 주 경로인 Messages API를 Python에서 Rust로 전환 완료했다고 발표했다. 이 경로 트래픽은 2024년 초부터 약 1,800배 늘었고, 결과는 요청당 CPU 약 70% 절감과 첫 토큰 중앙값 약 20% 단축이다. 서비스 중단 없이 끝냈는데, Claude가 약 1주 만에 핵심 경로 초안을 작성한 뒤 막힌 것은 검증이었다. 조직은 운영 중인 production API 자체를 정답 기준으로 삼아 두 버전의 응답 차이를 잡고, 발견된 차이의 수정을 에이전트가 자동으로 하게 하는 루프를 돌렸다. 수치는 자사 발표이며 독립 벤치마크는 아직 없다. 살아있는 시스템 전환을 생성과 검증의 역할 분리로 푼 조직 사례다. 크래프톤, 오픈웨이트 모델 Raon-1 mini 정식 공개 — Apache 2.0으로 상업 사용 허용

일본 정부 AI전략본부 작업그룹이 27일 AI추진법 개정안 요강을 냈다고 두 통신사가 보도했다. 2025년 제정 뒤 촉진 중심이던 법에 고성능 AI 제공자의 공격 대비 조치 의무화, 사고 보고 의무, 미응 시 벌칙 신설이 들어온다. 대상은 국내에 일정 규모 이용자를 둔 사업자이고, 정부기관인 AISI가 평가와 조사를 맡아 필요시 실사와 행정처분까지 간다. 공청회를 거쳐 2027년 통상국회 제출이 목표다. 다만 내용은 통신사 보도 기준이고 요강 원문과 벌칙의 범위·기준은 아직 확인되지 않았다. AI 규제가 촉진 중심에서 의무와 벌칙으로 이동하는 전환점 후보라 제도의 방향을 확인해 둘 소식이다. [해설 읽기]
