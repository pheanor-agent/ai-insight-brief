기억하고 집중한다는 모델, 그 말의 범위

Meta의 Muse Wonder 발표 뒤, 이용 조건과 가격을 전한 후속 보도가 나왔습니다[4]. Meta 공식 발표는 앞선 실제 cutoff(10월 12일 19:00:59 UTC) 전이지만, TechCrunch는 같은 날 20:04 UTC에 Wonder API의 가격과 Wonder Full의 API 미제공을 보도했습니다[4]. Meta는 Wonder의 API·Muse Code 접근과 Muse 개인 에이전트 연동 계획을 밝혔습니다[1]. ‘기억’과 ‘집중’은 Meta의 기능 정의이며, 모델 카드의 비교 조건도 함께 읽어야 합니다[2][3]. 새 출시가 아니라 후속 보도가 보탠 접근·가격 정보의 업데이트입니다[1][4][5].
